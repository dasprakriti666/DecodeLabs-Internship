# DecodeLabs Internship

## Week 2 Project
Automated Quality Inspection using Computer Vision

### Technologies Used
- Python
- OpenCV
- VS Code
- Git & GitHub

### Features
- Image Loading
- Grayscale Conversion
- Gaussian Blur
- Thresholding
- Contour Detection
- Bounding Box Detection
- Area Measurement
- PASS/FAIL Quality Inspection


## 📁 File Description
- `image_read.py` → Loads and displays input image
- `grayscale.py` → Converts image to grayscale
- `blur.py` → Applies Gaussian blur for noise reduction
- `threshold.py` → Converts image into binary format
- `contour.py` → Detects object contours
- `bounding_box.py` → Draws bounding boxes around objects
- `area_detection.py` → Calculates object area
- `quality_check.py` → Implements PASS/FAIL logic
- `test.py` → Main script to test workflow
- `coin.jpg`, `object.jpg` → Sample input images
